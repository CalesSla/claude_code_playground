# Claude Code Guidelines

## Documentation First

**ALWAYS refer to the relevant documentation files in the `/docs` directory before generating any code.**

Before writing or modifying code, check for applicable documentation:
- `/docs/ui.md` - UI components and styling guidelines
- `/docs/data-fetching.md` - Data fetching patterns and security requirements
- `/docs/data-mutations.md` - Data mutation patterns and server action requirements
- `/docs/auth.md` - Authentication standards using Clerk

This ensures consistency with project standards and avoids unnecessary rework.
